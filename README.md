# Princely Makhwara | Personal Portfolio

A responsive personal portfolio website introducing Princely Makhwara, highlighting his interests, skills, education, and experience, and providing ways to get in touch.

## Preview
https://princely24m.github.io/Personal-Webpage/Index.html

## Features

- Profile section with portrait and availability status
- Interests and technical skills
- Education and experience timelines
- Contact details and social profile links
- Responsive layout with an accessible hamburger menu on mobile

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Plus Jakarta Sans and JetBrains Mono

## Run Locally

No build tools or dependencies are required. Clone or download the repository, then open `Index.html` in a browser. Alternatively, use the Live Server extension in Visual Studio Code.

Google Fonts are loaded from the web, so they require an internet connection. The site itself can be opened locally without one; the browser will use fallback fonts if Google Fonts are unavailable.
